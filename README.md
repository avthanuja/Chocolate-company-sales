# 📌 Chocolate Company Sales Dashboard
This Power BI dashboard provides an in-depth analysis of the sales performance of a chocolate company. It includes insights into total sales, shipments, costs, and profits across different product categories and regions.

# 📊 Key Insights

Total Sales: $34M

Total Boxes Sold: 2M

Total Shipments: 6K

Total Costs: $13.52M

Total Profit: $20.52M

Profit Percentage: 60.29%

# 📈 Dashboard Features

Sales Trends: A line chart showing sales, boxes, shipments, costs, and profit over time.

Product Performance: A ranked list of products based on sales, profit, and target achievement.

Regional Sales Filter: Side navigation to filter sales by different regions (Australia, Canada, India, etc.).

Profitability Analysis: Profit percentage and weight-based performance indicators.

Shipment Distribution: A histogram showing total shipments by boxes.
